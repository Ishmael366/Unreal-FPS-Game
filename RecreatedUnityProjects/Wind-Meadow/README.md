# Wind Meadow

A newly implemented Unity study inspired by the tutorial topic. This is an original procedural prototype, not the recovered author's project or a reproduction of every episode of its series.

## Open

Use Unity 2021.3 LTS (source targets 2021.3.33f1), open this project folder, open `Assets/Scenes/Main.unity`, then press Play and Start. The level is generated when Play begins; an empty editor scene before Play is expected. The built-in rendering pipeline and legacy Input Manager are used. Default sound is off; M toggles it.

## Controls and objective

WASD explore; mouse look; Space jump; G toggle grass; T change sun angle; adjust wind slider.

Explore the rolling meadow and compare wind and lighting.

## Implemented scope

- Rolling terrain and collision
- 25 mesh grass patches with a custom wind shader
- Grass visibility, wind and sun controls

## Source structure

`ProjectDefinition.cs` selects this study's rules. `Layouts.cs` constructs its level. The runtime files provide collision-based movement, combat, pickups, objectives, cameras, and menus. Each project is independently openable. The reusable runtime is included in each archive so no external checkout is needed. Art and sound are generated by the new source; no paid or proprietary game assets are required.

## Verification and limits

C# compilation and pure game-rule/network checks are recorded in the accompanying batch validation report. Unity editor import, shader compilation, visual quality, gameplay balancing and playable exports have not been verified. Those checks and demos are deferred. A successful source compile does not establish a playable build.

This study reimplements the grass, wind and lighting topic in the built-in pipeline. It does not reproduce the original HDRP asset workflow or include the creator's grass models.
